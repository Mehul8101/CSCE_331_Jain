How to Build a PC

Materials Needed

  • Case
  • Power Supply Unit (PSU)
  • Motherboard
  • Central Processing Unit (CPU)
  • CPU Cooler
  • Memory (RAM)
  • Storage (SSD/HDD)
  • Graphics Processing Unit (GPU)
  • Operating System (OS)
  • Tools: Phillips Head Screwdriver, Anti-Static Wrist Strap

Steps to Build a PC

  • Step 1: Prepare Your Workspace - Ensure you have a clean, static-free environment.
  • Step 2: Install the Power Supply into the Case - Secure it with screws.
  • Step 3: Mount the Motherboard - Align with the case standoffs and screw it in.
  • Step 4: Install the CPU - Open the CPU socket, carefully place the CPU, and secure it.
  • Step 5: Attach the CPU Cooler - Apply thermal paste if needed, then secure the cooler.
  • Step 6: Insert the RAM - Align with the motherboard slots and press until it clicks.
  • Step 7: Install the Storage Drives - Secure them in the case and connect power/data cables.
  • Step 8: Install the GPU - Insert it into the PCIe slot and secure it with screws.
  • Step 9: Connect the Cables - Attach power, data, and any case cables to the motherboard.
  • Step 10: Test the Build - Connect to a monitor and power on to ensure everything works.
  • Step 11: Install the OS - Use a bootable USB drive to install your operating system.
